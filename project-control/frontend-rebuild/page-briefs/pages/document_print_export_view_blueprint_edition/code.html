1. Introduction

This Software Requirements Specification (SRS) documents the requirements for the Apollo V2 platform. It establishes the baseline for project scoping, design, and validation.

1.1 Purpose

The primary objective is to define the functional and non-functional requirements necessary to implement the distributed telemetry pipeline. All components must adhere to the security constraints defined in SEC-2.1.

2. System Architecture

The architecture relies on a microservices approach to ensure high availability and scalability. The data ingestion layer is decoupled from the processing layer.
